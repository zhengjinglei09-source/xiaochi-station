## 当前素材处理

项目保留一份 `docs/reference-character.png` 原稿副本。运行 `npm run assets:extract` 可以复现处理：精确矩形裁切、只清除与边缘连通的浅色背景，不生成或重新绘制人物。处理脚本有裁切坐标，`public/assets/character/provenance.json` 记录来源。最终 PNG 透明背景，保留原有像素和衣服、发型、眼镜、背包。

| 游戏方向 | idle | walk |
| --- | --- | --- |
| front | 原稿正面 | 原稿正面分层，双腿交替摆动、抬脚、身体轻摆 |
| back | 原稿背面 | 原稿背面分层，双腿交替摆动、抬脚、身体轻摆 |

所有占位 clip 均标记 `provisional: true`。原稿像素在 Canvas 内分层变换，没有重绘人物。人物高度 81，较初版放大 1.5 倍。步频跟随实际移动距离，碰墙、松手即回 idle。系统选择减少动态效果时关闭身体起伏及环境摆动、减弱腿部摆幅。

## 后续需要补齐

**沿用当前定稿人物，不重新设计。** 推荐交付透明 PNG：

- `idle/front`、`idle/back`、`idle/left`、`idle/right`：每方向至少 1 帧；可选 2 帧呼吸或轻微扶眼镜。
- `walk/front`、`walk/back`、`walk/left`、`walk/right`：每方向建议 4 帧，包含左右脚交替；建议 6～8 FPS。
- 每帧画布大小统一，例如 64×96；所有帧使用相同脚底锚点，人物高度和像素密度统一，避免切方向时大小跳变。
- 背包等不对称细节应在最终左右方向图中正确绘制；当前镜像只是接入占位。
- 可提供逐帧 PNG，或附带帧矩形、方向、状态、帧率、脚底锚点说明的 Sprite Sheet。当前 loader 直接接逐帧 PNG，若交付 sheet，在资源层加源矩形即可，移动代码无需改变。
- 如需参考图一致的中文字体，需要可用于网页的 WOFF2/TTF 和相应使用许可信息。

场景与 UI 是以参考配色为基础的代码绘制原型，不是从参考综合稿直接抠出的完整场景。现阶段视觉验收仍需用户试玩确认。

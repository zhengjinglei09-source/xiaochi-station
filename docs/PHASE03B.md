# Phase 03B · 学术号轻量 MVP

按用户确认，玩家可见名称继续用「学术号」，内部 ID 仍为 `postgrad`。本阶段到阶段结果为止，不开发复试、调剂剧情或其他路线。

## 复用与改动

新增内容集中在 `src/content/postgrad.ts`：6 个事件、对话分支、3 张词卡和 24 秒初试片段。`src/content/chapters.ts` 仅登记各路线使用的内容与起止文案。

继续使用原有 Campus / Dorm / Library、Player、动态摇杆、碰撞、InteractionSystem、DialogueSystem、DialoguePanel、QuizMiniGame、NPC 和本机章节检查点。没有考研专属地图、页面、事件系统、Quiz 系统或 ExamEngine，没有新依赖、NPC 或人物素材。

通用 Event 只增加可选的题目结果存放字段、短序列、结果池和自由活动间隔；Quiz 只增加可选的答错重试和完成文案。未设置这些选项时，社畜号继续使用原行为。`LifeGame` 负责通用序列与结尾显示；`main.ts`、`Game` 接通登车与返回。

## 六个事件

| 事件 | 入口 | 内容 |
| --- | --- | --- |
| 考哪儿？ | 图书馆电脑 | 冲一冲 / 匹配 / 稳妥，不显示概率或推荐 |
| 背了怎么又忘了 | 自习桌 | 看虚构便签、合上、回忆、再看；错答仍可推进 |
| 挺整齐 | 自习桌 | 角色上一份阅读五错五；随后 3 个高频词互动 |
| 有点不想考了 | 十月自习桌 | 继续或离开，均无道德评价 |
| 十二月初试 | 图书馆电脑 | 6 段各 4 秒；结束回校园，6 秒内无目标提示和结果通知 |
| 结果 | 手机 | 推进到 2027 年 2 月，统一显示进入复试，止于「学术号 · 第一阶段结束」及「下一站：复试」 |

初试片段是既有转场组件上的简短文字序列，没有新增考试地图或角色动画。玩家可自行决定阅读速度，没有为满足时长额外锁住对话。

词汇共 ambiguous、retain、reluctant 三题。答错显示红色「再想想」及解释，回到同一道；答对绿色并继续。结果记录首次答案与每题尝试次数，避免重试后抹去实际答题记录。社畜号测评仍答错给正确答案后直接下一题。

当前结局统一为 `postgradResult = "retest"`。选择继续并完成初试后进入复试，不读取 Quiz 正确率、背书记录或 resultSeed。当前考研事件已移除旧的三结果数据；状态类型保留旧值用于兼容旧检查点，新结果不再产生它们。

## 换乘与保存

`src/systems/route-transfer.ts` 提供 `selectRoute` 和 `returnToStation`。

- initialRoute 始终保留第一次登车选择；currentRoute 表示最近选择的路线，atStation 单独表示人在车站。
- routeProgress 仅保存每条路线的事件游标和结束标志。十月离开时提交选择与已有事实、保留十月节点；重新登上学术号可以重新考虑是否继续，不从头重玩。
- 保留所有已经记录的目标、答题、余额、事件和月份；日历不倒退。
- 十月换乘社畜号，从原有「我投什么？」开始，跳过已不合时序的九月开场；不修改社畜号事件数据和后续文案。
- 三条尚未开发的路线显示「这趟列车的故事还在准备中。」和「回到人生车站」，不进入其他剧情。
- 沿用 `xiaochi.chapter.v1`，兼容已有社畜号检查点，无新存档系统。刷新恢复稳定事件，未完成的对话/考试从事件开头重来。

新增状态：postgradTarget、postgradMemoryQuizResult、postgradEnglishQuizResult、postgradOctoberChoice、postgradResult；通用小字段：atStation、routeProgress、routeHistory、resultSeed、eventReadyAt。继续使用原有月份、章节、路线、completed 和 playSeconds。

## 验证方法

`tests/postgrad.spec.ts` 使用真实摇杆输入走完整继续路径和退出换乘路径，覆盖答错重试、考试时间、考后自由移动、统一复试结果、检查点恢复、重登学术号及转入社畜号。另检查 320×568、390×844、430×932 手机竖屏对话边界。

`POSTGRAD_PACED=1` 可运行阅读节奏模拟：每秒 5 个汉字、每段至少 1.8 秒、选项额外 3 秒。它不代表真人时长或真机验收。

冻结校验：`shasum -a 256 -c docs/phase03b-frozen.sha256`。包含社畜号事件、共用地图、摇杆、人物渲染入口和全部人物素材。

如当前浏览器仍保存已结束的社畜号，使用无痕窗口从人生车站测试，不需要删除已有进度。

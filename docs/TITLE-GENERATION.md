# 标题生成记录

- 使用工具：内置 imagegen，非 CLI/API 工作流。
- 最终接入路径：`public/assets/ui/title.png`。
- 输入：用户本轮提供的“大字标题”和“纸飞机”两张参考图。
- 输出：透明 PNG，白色像素字、深蓝描边与纸飞机。人物没有参与生成。

## 完整提示词

Use case: background-extraction / logo-brand. Asset type: transparent pixel game title header PNG for an existing Chinese mobile web game. Input image 1 is the exact approved title lettering reference, input image 2 is the small paper airplane reference. Create a clean transparent-background horizontal title lockup: exact Chinese text "小迟去哪儿" preserving the distinctive chunky, hand-lettered pixel shapes of reference 1, warm white fill, thick dark navy stepped pixel outline and tiny blue shadow. Keep all five characters legible and the original slightly playful varying heights. Add one small white-and-light-blue paper airplane immediately to the upper right of the final character, inspired by reference 2, pointing northeast, visually secondary. Tight horizontal composition, generous but minimal transparent padding, title occupies almost full width. Actual transparent alpha background. Remove all sky/cloud/city/photo backgrounds entirely. No additional text, punctuation, hearts, symbols or scene. Sharp consistent 16-bit pixel edges, not a smooth vector font. Do not include any character/person.

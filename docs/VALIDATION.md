## WebKit 测试环境说明

本机 macOS 14。最新 Playwright 1.63 驱动与本机冻结版 WebKit 2251 初始化协议不兼容，最初测试未能创建页面，并非游戏运行报错。最终固定 Playwright 1.58.2，并显式选择已安装的 WebKit 2251 完成上述检查：

```sh
XIAOCHI_WEBKIT_EXECUTABLE=/private/tmp/xiaochi-browsers/webkit_mac14_arm64_special-2251/pw_run.sh npm test -- --project=webkit --workers=2
```

其他机器正常 `npx playwright install webkit` 后使用 `npm test`，不需要设置本机路径。WebKit 的 `100dvh` 在 390×844 模拟尺寸中存在约 0.016 CSS 像素的舍入，因此布局断言允许小于 0.5 CSS 像素误差。

## 手机试玩顺序

1. 手机与电脑同一 Wi-Fi，打开开发服务的 Network 地址。
2. 页面打开直接看到人生车站和余小迟，不需要进入菜单。
3. 左侧不同位置按住、拖动，测试四向和斜向；右侧单独触摸不应移动。
4. 松手立即停下；触摸滑出左侧区域仍可继续控制。
5. 行走到长椅、花盆、公告牌和站台边缘，应被挡住；原行李箱位置应可直接走过。
6. 保持左手拖动，右手另点屏幕，左手控制不应被抢走。
7. 移动时切后台，再返回，应保持停止，需要重新按下才能移动。
8. 检查页面不滚动、缩放，人物与摇杆无遮挡，站台横穿节奏舒适。

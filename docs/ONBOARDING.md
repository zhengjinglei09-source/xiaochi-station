## 位置与顺序

1. 移动卡片左边距为容器宽度的 3.9%，顶端跟随地图 originY + 296，位于长椅（底部约 y222）与围栏（y359）之间。标题与副标题使用原生网页字体，方向符号沿用 ✥。自由探索时始终显示，按住、移动、松手均不消失。
2. 初始轻微强调约 2.4 秒；如果约 7 秒仍未实际移动，且没有按住摇杆，再强调一次。减少动画偏好下不播放呼吸。
3. 累计实际移动至少 3 地图像素后，出现“去不同月台看看吧”，以及朝向整个月台区域的单个像素箭头，旁边一行“向前走选择月台号”。不偏向某条路线。
4. 查看两个不同月台的信息后收起月台文字、箭头和角标。同一月台重复查看、查看公共站讯，均不算第二个月台。允许玩家随时直接登车，不设强制教程门槛。
5. 首次靠近站牌时出现“看看站讯”，成功打开信息后完成。首次靠近中央列车员有效交互范围时出现“和列车员聊聊”，在右侧交互按钮旁持续显示，没有短时消失。离开范围收起，未交互时返回还会出现；成功打开对话后完成，之后只留正常交互按钮。车门工作人员对话也可完成对话教学。
6. 对话、登车与完成画面期间收起操作引导；返回探索后恢复尚未完成的提示。移动提示恢复常驻。

# Phase 03C · 编制号

本阶段使用用户最新的“两次考试 → 面试 → 后续流程 → 入职”要求，覆盖 Product PRD 中较早的六节点与考公退出分支。考研列车仍保留此前确认的「学术号」。不进入下一路线，不制作考研复试。

## 文件与复用

- `src/content/civil-service.ts`：11 个事件、虚构岗位、题目、短对白和蒙太奇数据。
- `src/systems/activity.ts`、`src/ui/activity.ts`：通用筛选 / 单选 / 多选 / 点击排序，带取消、数量限制、焦点和触摸支持。
- `src/systems/quiz.ts`：原 QuizMiniGame 增加可选全局倒计时；旧题目不启用此模式，保留原有纠错 / 重试。
- `src/systems/events.ts`：增加本路线最少状态、卡片结果写入、对白变量替换、蒙太奇后继续对白。全部写入既有事件草稿，事件完成后才提交；关闭会撤销当前事件草稿。
- `src/systems/dialogue.ts`：仅透传可选场景片段标记。
- `src/life/vignette.ts`：候考、面试室、镜前、工作地点门口四类短画面，复用锁定人物素材；不是新可探索地图。
- `src/life/life-game.ts`：接入上述可选能力、考试后恢复移动与最终岗位显示；`src/content/chapters.ts` 和车站控制器登记编制号入口。
- `index.html`、`src/styles.css`：新增共享卡片面板、计时条和对应像素样式。
- `tests/civil-service.spec.ts`：完整流程、60 秒真实超时、卡片限制、取消、三个岗位、竖屏与实际触摸检查；旧测试只适配新增可用路线与面板定位。

继续复用 Campus / Dorm / Library、Player、动态摇杆、碰撞、Interaction、Dialogue、Quiz、手机提示、年月、检查点、现有 NPC。没有 CivilServiceEventSystem / CivilServiceQuizEngine / CivilServiceCampus / CivilServiceInterviewEngine，无新依赖和角色素材。

`docs/phase03c-frozen.sha256` 记录 03A、03B 全部事件数据、Route 配置、Route Transfer、地图、人物渲染入口、Player、摇杆及全部角色图片。本次这些文件逐字节不变。

## 实际路线

| 事件 | 玩家参与 | 时间 / 表现 |
| --- | --- | --- |
| 你国考看了吗？ | 打开公告，手动勾选3个筛选条件，从3个虚构岗位中选1个并报名 | 秋季；报名审核3秒 |
| 模拟行测 | 全局60秒，5题；可提前完成，也可留下未答题 | 言语、图形推理、数量、资料表、常识；随后9秒模考记录61→58→56 |
| 极简申论 | 阅读3段材料，选2～3个问题、2个措施，查看整理后的答题纸并提交 | 没有分数或标准答案判定 |
| 第一次国考 | 打印准考证后出发 | 11月；18秒早起、考点、上午行测、下午申论、铃响 |
| 考完了 | 恢复自由走动，找到朋友，选择一种考后回复 | 3秒无目标的空档；所有回复均推进 |
| 第一次查成绩 | 主动查分，再按“搜索姓名”自动搜余小迟 | 次年1月；64.2 / 61.5，0个匹配结果，“哦。” |
| 怎么又来了 | 新省考公告；直接勾选熟悉条件，第二次选岗、报名 | 条件327→186→94→38改为218→120→57→23；无重复教程，报名2秒 |
| 第二次考试 | 点击安排五类题的顺序，可撤销重排，数量可放最后 | 3月；10秒省考蒙太奇，不重复行测/申论 |
| 进入面试 | 查成绩、确认复审通知 | 4月；短Loading，进面，5秒资格复审 |
| 面试 | 候考、进场，回答2道工作情境题，各有不同短反馈 | 无评分；面试通过后12秒综合成绩、体检、考察、公示和报到通知 |
| 第一天 | 镜前、门口与朋友对话、走进去 | 毕业后；门牌及结尾显示第二次选择的岗位 |

岗位全部虚构，只有学历、应届身份、基层工作经历三个条件；没有专业选项、真实机关名、竞争率或推荐。第一次和第二次均从 A市综合事务岗、家乡行政事务岗、B市综合管理岗中自主选择。

行测时钟使用真实时间截止点，阅读和切后台仍计时；到零即关闭当前题目，拒绝超时答案，显示完成/未完成。早交卷只显示“已交卷”，不强迫玩家空等60秒。关闭未完成事件不保存半份答卷，重新打开重新计时。

## 状态和结局

记录 `civilServiceFirstJob`、`civilServiceSecondJob`、两次 Filters、`civilServiceQuizAnswers`、`civilServiceQuizCompletedCount`、`civilServiceEssayChoices`（problems / measures）、`civilServiceExamOrder`、`civilServiceFirstResult`、`civilServiceSecondResult`、`civilServiceInterviewChoices`、`civilServiceInterviewResult`、`civilServiceFinalJob`。

结果固定为第一次未进面、第二次进面、面试通过并完成后续流程；不读取 Quiz、申论、岗位人数、题目顺序或面试答案来决定录用。`civilServiceFinalJob` 直接复制 `civilServiceSecondJob`；最终显示「编制号 · 到站」、余小迟 · 2027、岗位名称。不评价其他人生路线，不表达现实成功率。

本路线不调用 Return To Station；考研十月换乘仍保留。既有本机保存键不变，完成事件后刷新恢复；正在进行的互动从该事件重新开始。未开发列车仍只有留子号、待机号的准备中提示。

## 节奏与验证

完整功能检查使用实际摇杆走地图，不传送。阅读计时使用 `CIVIL_PACED=1`：对白每秒6个汉字、最低1.3秒；选项额外3.5秒；岗位卡停留6秒，材料和卡片有独立阅读/思考停留；限时题每题思考约12.5秒。因此计时为可复现的模拟，不等于真人试玩时长，也不保证所有阅读速度都在同一区间。游戏不使用这套测试停留限制玩家。

## 流程参考

只核对公告→报名→公共科目笔试→面试→综合成绩→体检考察→公示的基本顺序。参考国家公务员局公告的[政府转载页](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/tzxx/202510/t20251015_4224742.html)，不复制现实网站截图、机关、职位、题目或具体日期；实际报考安排有年度和地区差异。游戏采用虚构岗位和固定剧情，不是报考指南。
